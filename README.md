# دستیار صوتی فارسی (Dastyar Sotii)

اپلیکیشن اندروید دستیار صوتی فارسی برای فرد کم‌بینا. دو قابلیت اصلی: برقراری تماس با مخاطبین، و خواندن پیامک‌های دریافتی — همراه با گفتگوی ساده فارسی.

## وضعیت فعلی: MVP فاز ۱

این نسخه اول (اسکلت قابل‌اجرا) است. برای اینکه مسیر کامل صدا→عملیات هرچه زودتر روی گوشی واقعی قابل تست باشد، از پیاده‌سازی‌های سبک زیر استفاده شده که همگی پشت یک لایه Abstraction قرار دارند و در فازهای بعد قابل تعویض‌اند:

| ماژول | پیاده‌سازی فعلی | برنامه فاز بعد |
|---|---|---|
| تشخیص گفتار (STT) | `AndroidSystemSttProvider` (موتور سیستم اندروید) | `VoskSttProvider` — کاملاً آفلاین، بدون وابستگی به گوگل |
| متن‌به‌گفتار (TTS) | `AndroidSystemTtsProvider` (موتور سیستم اندروید) | Piper (صدای فارسی) + eSpeak-NG fallback |
| تشخیص Intent («مغز») | `RuleBasedLlmProvider` (Regex فارسی، رایگان و آفلاین) | افزودن `OnDeviceLlmProvider` اختیاری (مدل کوچک محلی) برای گفتگوی بازتر |

همه این تصمیم‌ها در سند «تحلیل امکان‌سنجی» توضیح داده شده‌اند (مبنای اصلی: ایران تحریم LLMهای ابری است، پس مسیر پیش‌فرض باید کاملاً آفلاین/رایگان بماند).

## ساخت APK (بدون نیاز به کامپیوتر)

این ریپو یک GitHub Actions workflow دارد (`.github/workflows/build.yml`) که با هر push به شاخه `main` یا اجرای دستی، به‌صورت خودکار:
1. پروژه را با Gradle می‌سازد (`assembleDebug`)
2. یک Release جدید با APK پیوست می‌سازد — از تب **Releases** همین ریپو قابل دانلود است.

برای اجرای دستی: تب **Actions** → workflow «Build APK» → **Run workflow**.

## نصب روی گوشی

چون این اپ از Google Play منتشر نمی‌شود، باید مستقیم (sideload) نصب شود:
1. APK را از تب Releases دانلود کنید.
2. هنگام نصب، اگر گوشی هشدار داد، «نصب از منابع ناشناس» (Install unknown apps) را برای مرورگر/فایل‌منیجری که با آن APK را باز کرده‌اید فعال کنید.
3. اپ را باز کنید و همه دسترسی‌های درخواستی (میکروفون، مخاطبین، تماس، پیامک) را بدهید.

## ساختار پروژه

```
app/src/main/java/ir/mas/dastyar/
  core/        هماهنگ‌کننده مکالمه (ConversationViewModel) + وضعیت UI
  intent/      تشخیص Intent (LlmProvider + RuleBasedLlmProvider)
  stt/         تبدیل گفتار به متن
  tts/         تبدیل متن به گفتار
  contacts/    جست‌وجوی مخاطب
  calling/     برقراری تماس
  sms/         خواندن پیامک + ناوبری (بعدی/قبلی/دوباره/توقف)
  ui/          صفحه اصلی Compose، مدیریت Permission، تم
```

## محدودیت‌های شناخته‌شده این نسخه (MVP)

- کیفیت گفتگوی آزاد (CHAT) محدود است چون از یک طبقه‌بند Regex استفاده می‌شود، نه یک مدل زبانی واقعی. این محدودیت عمدی است تا اولین نسخه سریع، رایگان، و بدون هیچ وابستگی سنگین (بدون نیاز به دانلود چند صد مگابایت مدل) قابل build و تست باشد.
- بعد از هر پاسخ سیستم، کاربر باید دوباره روی دکمه میکروفون ضربه بزند (شنیدن پیوسته/خودکار پیاده‌سازی نشده — برای جلوگیری از فعال‌شدن ناخواسته با صدای محیط).
- تشخیص مخاطبانی مثل «مامانم» فقط در صورتی کار می‌کند که دقیقاً همین‌طور در دفترچه مخاطبین ذخیره شده باشد.
- STT/TTS فعلی به سرویس‌های گوگل روی گوشی وابسته‌اند (فاز بعد این وابستگی حذف می‌شود).
